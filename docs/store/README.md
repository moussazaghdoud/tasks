asks for, taken on the device itself. Apple scales them down for smaller
phones, so this one size is all the listing needs.

## Retaking them

They have to be retaken whenever the app's look changes — the six they
replaced showed a cream design and demo data that no longer exist, which is
the kind of mismatch App Review rejects under Guideline 2.3.3.

Take them on the phone, in the order above, and check before uploading:

- nothing private in the thoughts or the meeting titles; the listing is public
- the battery is not nearly flat, which reads as carelessness
- the build in the screenshots is the one being submitted
